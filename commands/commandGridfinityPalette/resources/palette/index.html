Advanced
Search range Credits a half-cell when an opening's leftover space is at least half the grid pitch. Unchecking this can change which grid size is recommended. Priority weighs one dimension's leftover space more heavily when ranking grid sizes. "Only" ignores the other dimension's leftover space entirely (e.g. depth waste at the back of a drawer you don't care about).
Dimensions
Openings to fit ⓘThe inside size of each drawer or cabinet opening you want to fill, in millimetres (not grid units). Width is left-to-right, depth is front-to-back. Measure the usable space inside; the optimizer works out how many grid cells fit and how much is left over.
